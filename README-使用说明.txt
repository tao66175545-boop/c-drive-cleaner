C 盘清理工具

当前版本：v1.4.7

一、使用方式
1. 解压整个文件夹，不要只拿其中一个文件。
2. 双击“C盘清理.bat”。
3. 在图形界面点击“开始扫描”。扫描默认不删除任何文件。
   - 默认跳过全用户目录空间剖析，优先快速生成可勾选清单。
   - 系统允许读取 NTFS USN Journal 时会使用增量扫描；无权限或 Journal 不可用时自动回退，不会自动请求管理员权限。
4. 扫描完成后进入“清理清单”，查看每项的占用、建议与影响说明，自行勾选需要处理的项目。
5. 确认汇总的数量和预计释放空间后，点击“执行所选项”。
6. 如需对话式辅助，可进入“智能助手”页：输入“请帮我清理低风险缓存”，助手会先只读扫描、勾选建议项并打开确认框，只有你点击“是”才会清理。
7. 旅行、酒店、机票、火车或景点问题可选择交给飞猪 FlyAI 查询；首次使用会请求本次会话授权，且不会发送磁盘扫描数据。
8. 对话气泡中的文字可以用鼠标拖选需要的片段，按 Ctrl+C 或右键选择“复制”；右键菜单也支持“全选”。

二、文件说明
- C-Drive-Cleaner.ps1：主程序，负责扫描、诊断、安全清理和报告。
- C-Drive-Cleaner-UI.ps1：WinForms 图形界面外壳。
- assets\logo-animated.svg：上传的曙光云 Logo 动画源文件。
- assets\logo-animated-sprite.png：由 SVG 浏览器时间轴预渲染的 135 帧 Logo（60fps、2.22 秒），用于 WinForms 平滑播放。
- assets\cleaning-sprite-source.png：清理小助手的 8 帧透明序列图，界面启动时自动裁剪加载。
- C盘清理.bat：双击启动入口。
- AgentHost.ps1：可选云端 Agent 的隔离模型调用进程。
- TravelHost.ps1：可选飞猪 FlyAI 旅行查询的隔离进程。
- assets\assistant-user-custom.png：智能助手聊天中使用的固定用户头像。

三、安全边界
- 空间大户、重复目录、微信/QQ 根目录、休眠文件、页面文件只诊断，不自动删除。
- 微信/QQ 图片与视频附件会作为独立的“谨慎选择”项目显示，默认不勾选；执行后移入系统回收站，清空回收站前可恢复，且不能与“清空回收站”同批执行；仅覆盖应用的指定图片/视频附件目录，不处理聊天数据库、FileRecv 或整个账号目录。
- 清理模式只处理主程序清单中的缓存和临时文件。
- 图形界面只会执行用户在本次扫描清单中勾选的固定项目 ID；不接受文件路径输入，未知或过期项目 ID 会被拒绝。
- 清理计划有效期为 30 分钟；清理规则、计划快照或微信/QQ 用户内容发生变化时会要求重新扫描。
- 清理前图形界面会再次确认。
- 主程序包含保护路径检查，并跳过 junction/symlink 重解析点。
- 需要管理员权限的系统项目会在非管理员模式下跳过。
- 程序不会自动提权；每次清理都需要本次扫描生成的选择计划，操作日志保存在 %LOCALAPPDATA%\CDriveCleaner\journals。
- 增量索引只保存文件引用号与稳定项目 ID，不保存路径、文件名或内容；微信/QQ 用户内容不会进入索引，清理时会重新扫描核验。
- 点击“执行所选项”并确认后，右上角清理小助手会播放序列帧；清理完成后恢复静止状态。
- 左侧 Logo 默认显示完整品牌图，鼠标移入或点击时按源文件的 2.22 秒速率播放一次；结束后恢复与动画最后一帧一致的静止状态。
- HTML 报告保存在 %LOCALAPPDATA%\CDriveCleaner\reports，不写入程序目录。
- 云端 Agent 使用 Windows DPAPI CurrentUser 加密保存 API Key；不会把 Key 写入项目、日志、命令行或发布包。云端只接收用户问题和稳定 ID、大小、风险、恢复方式等摘要，不发送原始路径、用户名、机器名、文件内容或运行日志。
- Agent 只能导航页面、发起或取消扫描、调整可撤销勾选；最终清理必须由用户在原生确认框中决定。配置页“禁用并移除凭据”会删除配置并恢复离线助手。
- 对话式清理只会自动勾选本次扫描中的低风险建议项；否定/取消表达不会触发清理，微信/QQ 图片与视频仍默认不勾选。
- 飞猪能力只接收当前旅行问题并提供只读建议，不接收扫描结果、路径、日志、API Key 或清理计划，也不会自动下单或支付。

四、环境要求
- Windows PowerShell 5.1
- Windows Forms（Windows 系统通常自带）
- 建议使用 Windows 10/11
- 可选飞猪旅行建议需要 Node.js 18+ 与官方 @fly-ai/flyai-cli；未安装时不影响清理功能。

五、命令行安全自检
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\C-Drive-Cleaner.ps1 -SelfTest
